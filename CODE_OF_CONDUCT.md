# Code of Conduct

## Notre Engagement

Nous nous engageons a rendre la participation dans notre projet une experience libre et accessible a tous. Nous utilisons le code de conduite suivant pour definir les attentes pour notre communaute.

## Nos Standards

Les comportements suivants sont attendus :

- Utiliser des inputs accueillants et inclusifs
- Respecter les points de vue differents
- Accepter la critique constructive
- Se concentrer sur ce qui est le mieux pour la communaute
- Montrer de l'empathie envers les autres membres

Les comportements suivants sont inacceptables :

- Le harcèlement sous toutes ses formes
- Les commentaires trolls ou insultants
- Les attaques personnelles ou politiques
- La publication d'informations privees sans consentement
- Toute autre conduite qui pourrait etre consideree comme inappropriee

## Responsabilites

Les maintainers du projet sont responsables de clarifier les standards de comportement acceptable et prendront des actions correctives appropriees en reponse a tout comportement inapproprie.

## Portee

Ce code de conduite s'applique dans tous les espaces du projet, y compris les issues, pull requests, et les interactions sur les reseaux sociaux.

## Application

Les cas de harcèlement ou de comportement inacceptable peuvent etre signales aux maintainers du projet.

## Attribution

Ce Code of Conduct est adapte du [Contributor Covenant](https://www.contributor-covenant.org/).
